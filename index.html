Tech Future

O Tech Future é um site fictício criado para apresentar lançamentos, tendências e soluções do universo tecnológico.

O projeto foi desenvolvido com estrutura semântica, Bootstrap, CSS externo, Flexbox, responsividade e manipulação do DOM com JavaScript.

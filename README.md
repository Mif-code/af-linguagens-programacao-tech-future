# Tech Future

## Tema
Site fictício sobre tecnologia, inovação, inteligência artificial, robótica, computação em nuvem, dispositivos inteligentes e automação.

## Integrantes
- Aluno: Moises Ivanildo Ferreira - RA: 251553

## Páginas do Projeto
- Home (`index.html`)
- Galeria / Novidades / Lançamentos (`galeria.html`)
- Contato (`contato.html`)

## Tecnologias Utilizadas
- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- GitHub

## Funcionalidades
- Menu responsivo com Bootstrap Navbar
- Carrossel Bootstrap com 3 imagens
- Galeria de imagens com cards
- Filtros por categoria na galeria usando JavaScript
- Formulário de contato com validações HTML5
- Validação adicional do formulário com JavaScript
- Mapa incorporado com iframe
- Botão voltar ao topo
- Alternância de tema claro/escuro
- Hover, transições, animações e efeito com `-webkit-background-clip`
